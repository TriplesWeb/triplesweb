# PR #31 격리 미리보기

PR #29(헤더·필터·모달)와 PR #30(로드 성능)을 합친 검토용 서버입니다.
Raspberry Pi의 **별도 컨테이너**만 갱신하며 main 운영 컨테이너, 협업자 로컬 IntelliJ, `.env`는 변경하지 않습니다.

GitHub Actions의 **PR 미리보기**와 **PR 모바일 HTTPS 미리보기** 실행 요약에서 접속 주소와 배포 커밋을 확인합니다.

- Tailscale HTTP: 서버 Tailscale 주소의 `18031` 포트. 인터넷에 공개하지 않습니다.
- 휴대폰 HTTPS: Cloudflare 임시 주소. Tailscale 없이 관리자 비밀번호로 로그인합니다.

## 데이터와 로그인

협업자와 **공개 DB 스냅샷만** 공유합니다. 운영 MariaDB에 미리보기 계정이 쓰지 않습니다.

첫 배포 때 운영 스키마를 읽고 허용 목록의 공개 데이터만 `triples_pr31_preview`로 복사합니다.
개인 계정·즐겨찾기·전송 인덱스 등 나머지 테이블은 복사하지 않습니다.
런타임 DB 계정 `pr_preview_31`은 미리보기 스키마에만 권한이 있습니다.
관리자 비밀번호는 서버 안에서만 전달하고, 세션·CSRF 쿠키 이름은 `PR31SESSION`이라 운영 로그인과 섞이지 않습니다.
관리자 수정, 파일 업로드는 `previews/pr-31`에만 반영됩니다.
기존 이미지가 없으면 운영 사이트의 공개 이미지 주소로 이동합니다.
전송 인덱싱과 업로드 동기화는 중지하며 COSMO 인증 토큰을 전달하지 않습니다.
다음 배포에도 미리보기 데이터를 유지하므로 복사 시점 이후 운영 데이터 변경은 자동 반영하지 않습니다.

미리보기 앱은 CPU 0.75·메모리 512MB로 제한되어 운영 컨테이너와 자원을 나눕니다.

## 휴대폰 진단

공통 레이아웃을 사용하는 화면 우측 하단 **미리보기 · 진단** 버튼을 누릅니다.
배포 커밋, 데이터 복사 시점, fetch 요청 경로·상태·시간, 스크립트 오류 위치를 볼 수 있습니다.
요청 본문·쿼리·인증 헤더는 수집하지 않습니다.

PR 종료 시 해당 미리보기 컨테이너와 전용 DB/계정을 정리합니다.
미리보기 업로드 파일은 서버의 `previews/pr-31` 아래에 보존합니다.
