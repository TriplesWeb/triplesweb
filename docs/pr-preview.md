# PR #26 모바일 미리보기

PR #26 갱신 시 자동 검사 후 Raspberry Pi의 별도 컨테이너를 갱신합니다.
main과 운영 컨테이너는 변경하지 않습니다. 로컬 IntelliJ의 properties 수정도 필요하지 않습니다.

GitHub Actions의 **PR 미리보기** 실행 요약에서 접속 주소와 실제 배포 커밋을 확인합니다.
휴대폰은 서버에 접근 가능한 동일 Tailscale 네트워크에 연결해야 합니다.
서버 Tailscale 주소의 18026 포트만 사용하며 인터넷 전체에 공개하지 않습니다.

## 데이터와 로그인

첫 배포 때 운영 스키마를 복제하고 허용 목록의 공개 데이터만 복사합니다.
개인 계정·즐겨찾기·전송 인덱스 등 나머지 테이블의 데이터는 복사하지 않습니다.
런타임 DB 계정은 미리보기 스키마에만 권한이 있습니다.
관리자 비밀번호는 기존 값을 서버 안에서 전달하지만 로그인·CSRF 쿠키는 운영과 다릅니다.
관리자 수정, 파일 업로드는 미리보기 데이터에만 반영됩니다.
기존 이미지가 없을 때 운영 사이트의 공개 이미지 주소로 이동합니다.
전송 인덱싱과 업로드 동기화는 중지하며 COSMO 인증 토큰을 전달하지 않습니다.
다음 배포에도 미리보기 데이터를 유지하므로 복사 시점 이후 운영 데이터 변경은 자동 반영하지 않습니다.

## 휴대폰 진단

공통 레이아웃을 사용하는 화면 우측 하단 **미리보기 · 진단** 버튼을 누릅니다.
배포 커밋, 데이터 복사 시점, fetch 요청 경로·상태·시간, 스크립트 오류 위치를 볼 수 있습니다.
요청 본문·쿼리·인증 헤더는 수집하지 않습니다.
진단 복사는 HTTPS 환경에서는 클립보드, HTTP 환경에서는 선택 가능한 텍스트 창으로 제공합니다.
Java 중단점 디버깅 기능은 제공하지 않습니다.

PR 종료 시 해당 미리보기 컨테이너와 전용 DB/계정을 정리합니다.
미리보기 업로드 파일은 서버의 previews/pr-26 아래에 보존합니다.
