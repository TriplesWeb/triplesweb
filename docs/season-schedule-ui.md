# 시즌 필터와 일정 분류

- 시즌 빠른 선택 버튼은 오브젝트 목록·계정 컬렉션·전송 기록·교환/거래 작성의 기존 시즌 컨트롤과 연동한다. 기존 드롭다운, 체크박스 다중선택과 서버 검색 파라미터는 유지한다. 동적으로 추가된 시즌도 반영한다.
- Atom01은 노랑, Binary01은 연두 계열이며 시즌 이름/차수에 따라 색을 구분한다. 선택 시 색을 채우고 모바일에서는 버튼 줄을 가로로 스크롤한다.
- 멤버 광택은 3.5초 주기, 1.5초 이동, 2초 대기다. 정적인 광택 레이어의 transform/opacity만 바꾸고, 대체 초상화에도 레이어를 보완한다. 모션 감소 설정에서는 멈춘다.

일정은 팬사인회(보라), 방송(주황), 기념일(멤버 상징색), 발매(빨강), 행사(하늘색), 기타로 분류한다. 기존 일정의 AUTO는 제목으로 표시 분류만 추정한다. 저장된 제목을 일괄 변경하지 않는다. 관리자가 지정한 분류가 우선한다.

기념일 색은 연결된 멤버의 프로필 상징색을 사용한다. 멤버 연결이 없는 기존 일정은 제목에서 공식 이름/영문명을 찾아 색을 보완하고, 특정할 수 없으면 기본색을 쓴다. 복수 멤버일 때는 S 순서의 첫 멤버를 사용한다. 🎂는 표시 제목에만 붙여 반복 수정해도 중복 저장하지 않는다.

## DB 변경

V37은 schedule.category VARCHAR(24) 컬럼을 AUTO 기본값으로 추가한다. 공유 운영 DB에 연결된 로컬 실행도 Flyway를 통해 이 마이그레이션을 적용한다. 기존 main은 추가 컬럼을 무시할 수 있으며, 이번 작업에서 실제 운영 DB에 직접 접속하거나 데이터를 수정하지 않았다.

## 검증

- 일정 분류 저장/재조회, 이전 수정 호출과의 호환, 종료일 검증, 제목 자동 분류, 상징색·케이크, 관리자 권한·JSON 안전 처리
- 실제 FullCalendar·Bootstrap을 사용한 등록/수정, 저장 ID와 분류 반영, CSRF 헤더, 단일/다중 시즌 필터 연동·초기화·동적 옵션·키보드·모바일
- 기존 Chrome/Safari 페이지 검사와 멤버 선택 효과 검사. 실제 기기 FPS/CPU 수치는 측정하지 않았다.
