# 아티스트 페이지 지연 개선

코드에서 확인한 초기 로딩 부담:

- 그룹 소개만 보이는 첫 요청에서도 전체 멤버의 콘텐츠를 조회했다. 사진·영상 각 2,000건, 전체 공식 미디어와 일정에서 멤버별 목록을 만들었다.
- 선택하지 않은 멤버의 콘텐츠 HTML과 이미지 주소도 처음부터 포함했다.
- 선택된 탭은 빛 애니메이션과 이미지의 중첩 드롭 섀도를 계속 그렸다.

첫 화면에서는 멤버 콘텐츠를 조회하지 않는다. 선택한 멤버의 HTML 조각을 한 번만 요청하고, 같은 페이지에서 다시 방문하면 재사용한다. 오류는 명시적으로 재시도할 수 있다. 숨은 멤버 사진도 선택할 때 주소를 넣는다.

개별 조회는 사진·영상 각각 최대 40건의 후보, 공식 미디어·일정 각각 최대 5건으로 제한한다. 상시 빛 효과와 이미지 필터는 제거하고 선택 테두리는 유지한다.

검증은 초기 콘텐츠 조회 0회, 선택된 멤버 한 명만 처리, 전역 조회 미사용, 중복 요청·재시도·키보드 탭·직접 탭 주소와 모바일 화면을 대상으로 한다. 운영 서버의 실제 지연 시간이나 FPS 향상 수치는 측정 전후 비교 없이 주장하지 않는다.
